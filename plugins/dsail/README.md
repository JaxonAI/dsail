# DSAIL plugin

Check documents and AI output against written policy. DSAIL turns a written policy, like a compliance manual, filed rating rules, insurance policy wording or a release standard, into a ruleset and records the rule behind every result. Use it for policy compliance, eligibility, rating and claims checks. It applies the rules a policy already states; it does not decide who may act or who signs off.

Turn a written policy into rules a program can check, and get the same answer every time.

The plugin carries the DSAIL skills (the authoring sequence and grammar, and
two guides to the policy families it is most often used for) and the `dsail`
MCP server. The server is the hosted DSAIL service at https://agents.jaxon.ai/mcp, which asks you
to sign in with Google or GitHub on first use. A client that runs local
servers launches the `dsail mcp` proxy from the `dsail` Python package instead,
which forwards to the same service over HTTPS. The service receives the policy
you compile, the values you check against it and the rulesets and approvals you
save; your documents stay with your own model, which does the extraction.

Setup for each client is in the quickstarts at https://docs.agents.jaxon.ai, where every page is
also served as markdown for agents.
